# 物理提分助手

八年级物理自适应学习网页应用，专为物理薄弱学生设计。

## 在线访问

- **学生端（GitHub Pages）**：https://forestrain-git.github.io/Kids-Education/
- **学生端（Vercel）**：https://kids-education-eight.vercel.app/
- **家长看板**：https://forestrain-git.github.io/Kids-Education/parent.html

## 核心功能

- **自适应推荐**：根据掌握度动态推送"比能力高一点点"的题目
- **艾宾浩斯复习**：按 1/3/7/14/30 天间隔自动复现旧题
- **引导式解析**：3 步引导（启发问题 → 关键提示 → 完整解答）
- **知识地图**：可视化 29 个知识点的掌握进度
- **错题本**：自动收录，支持专项重练
- **数据备份**：支持导出/导入 JSON，防止数据丢失

## 使用说明

1. 在浏览器中打开学生端链接即可开始学习
2. 建议添加到书签或主屏幕，方便每日访问
3. 定期在"设置"页导出数据备份
4. 家长看板从同一浏览器的 localStorage 读取数据，需在同一设备上查看

## 数据说明

- 学习进度保存在浏览器本地（localStorage）
- **清除浏览器缓存会丢失数据**，请务必定期导出备份
