## 八、回归核心流程（每次版本更新必测）

### 流程 A：首次使用到完成练习

- [ ] A1. 清除 localStorage，刷新 index.html
- [ ] A2. 验证首页显示初始状态
- [ ] A3. 点击"开始练习"
- [ ] A4. 完成 3 道题（2 对 1 错，错的选择标签）
- [ ] A5. 到达结果页，验证统计数据
- [ ] A6. 返回首页，验证数据更新
- [ ] A7. 进入错题本，验证错题存在
- [ ] A8. 进入知识地图，验证节点状态变化
- [ ] A9. 进入设置，验证数据可导出
- [ ] A10. 打开 parent.html，验证看板数据一致

### 流程 B：数据备份与恢复

- [ ] B1. 有学习数据状态下导出备份
- [ ] B2. 清除 localStorage
- [ ] B3. 验证应用恢复初始状态
- [ ] B4. 导入刚才的备份文件
- [ ] B5. 验证所有数据恢复正确
- [ ] B6. 验证 parent.html 数据同步

### 流程 C：错题复习闭环

- [ ] C1. 故意答错 2 道题
- [ ] C2. 进入错题本，验证错题显示
- [ ] C3. 点击"全部重练"
- [ ] C4. 答对这 2 道题
- [ ] C5. 返回错题本，验证错题已清空
- [ ] C6. 验证首页"待复习错题"计数为 0
