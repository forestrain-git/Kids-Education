# 跨设备数据同步方案 — 详细分析

## 方案概述：URL 分享链接 + CloudBase 数据库

核心思路：用 URL 参数 `?uid=xxx` 作为用户标识，数据存储在腾讯云 CloudBase 数据库中。学生端和家长看板通过同一 uid 访问同一份数据。

---

## 详细利弊分析

### 优势

| 优势 | 说明 |
|------|------|
| **零登录门槛** | 打开即用，不需要微信授权、手机号、密码。对初中生极其友好 |
| **数据跟随链接** | 收藏链接 = 保存数据，换设备只需打开同一链接 |
| **家长天然同步** | 孩子把链接发给家长，家长看到的就是实时数据 |
| **改造成本低** | 前端改动集中在 Storage 层，业务逻辑完全不动 |
| **可回滚** | 保留 localStorage 作为 fallback，网络异常时不中断使用 |
| **费用极低** | CloudBase 免费额度：5万次/天云函数调用 + 2GB 数据库，个人使用绰绰有余 |

### 劣势与风险

| 劣势 | 影响 | 缓解措施 |
|------|------|----------|
| **uid 明文暴露** | 任何人拿到链接就能读写数据 | 可加装简单密码（4位数字），默认不设 |
| **网络依赖** | 无网时无法保存/读取 | 保留 localStorage 缓存，有网时自动同步 |
| **云函数冷启动** | 首次调用延迟 1-3 秒 | 可配置云函数预置并发（有轻微费用） |
| **腾讯云绑定** | 换云服务商需重写 | 接口抽象一层，实际改动小 |
| **数据量上限** | 单文档 16MB，state 通常 < 100KB | 当前完全够用，未来可分片 |

### 与方案1（微信登录）对比

| 维度 | 方案2（URL链接） | 方案1（微信登录） |
|------|-----------------|------------------|
| 用户体验 | 打开即用，无门槛 | 需微信授权，部分用户排斥 |
| 数据安全 | 链接即钥匙，可分享 | 微信授权，相对安全 |
| 家长查看 | 直接发链接 | 需家长也微信登录绑定 |
| 开发工作量 | 2-3 天 | 4-5 天（含微信 SDK 调试） |
| 适用场景 | 个人/家庭使用 | 班级/学校批量使用 |
| 费用 | 几乎免费 | 可能涉及微信认证费用 |

**结论**：对于"孩子在家自学、家长偶尔查看"的场景，方案2更合适。

## 关键代码变更预览

### 页面入口逻辑（新增）

```javascript
// 放在 app.js 最前面，页面加载时执行
(async function init() {
  const params = new URLSearchParams(location.search);
  let uid = params.get('uid');

  if (!uid) {
    // 首次访问，生成 uid 并重定向
    uid = await CloudSync.generateUid();
    location.href = location.pathname + '?uid=' + uid;
    return;
  }

  // 有 uid，从云端拉取数据
  const remoteState = await CloudSync.getState(uid);
  if (remoteState) {
    localStorage.setItem(Storage.KEY, JSON.stringify(remoteState));
  }
})();
```

### Storage.saveState 改造

```javascript
saveState(state) {
  localStorage.setItem(this.KEY, JSON.stringify(state));

  // 异步同步到云端（不阻塞 UI）
  const uid = new URLSearchParams(location.search).get('uid');
  if (uid) {
    CloudSync.saveState(uid, state).catch(console.error);
  }
}
```

## 费用估算

CloudBase 免费额度（每月）：
- 云函数调用：500 万次
- 数据库读：500 万次
- 数据库写：300 万次
- 出站流量：1 GB

按每天 100 题、每次保存 1 次计算：
- 月云函数调用：~3000 次
- 月数据库读写：~3000 次
- **结论：完全在免费额度内**
